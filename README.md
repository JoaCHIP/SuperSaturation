# SuperSaturation
An alternative to hue/saturation and gamma curve control which I think makes better looking results. I hope people will port this to other plugin formats and graphics tools. Currently the plugin supports operating in RGB color mode in both 8 and 16 bits per color channel.

The plugin currently has these adjustments:
- Saturation: Amount of color, behaves differently than Photoshop's saturation control.
- Liveliness: Somewhat similar to "vibrance", but again, looks different.
- Gamma: This adjusts the gamma in such a way that the colors are retained.
- Contrast: This adjusts the contrast in such a way that the colors are retained.
- Warmth: A kind of white balance adjustment.
- Hue Shift: Similar to Photoshop's hue shift, but looks different.
