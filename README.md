# SuperSaturation
An alternative to hue/saturation and gamma curve control which I think makes better looking results. I hope people will port this to other plugin formats and graphics tools. Currently the plugin supports operating in RGB color mode in both 8 and 16 bits per color channel.

The plugin currently has these adjustments and ranges:
- Saturation (0 to 100): Amount of color, behaves differently than Photoshop's saturation control.
- Liveliness (0 to 50): Somewhat similar to "vibrance", but again, looks different.
- Gamma (-100 to 100): This adjusts the gamma in such a way that the colors are retained.
- Contrast (-200 to 200): This adjusts the contrast in such a way that the colors are retained.
- Warmth (-50 to 50): A kind of white balance adjustment.
- Hue Shift (-180 to 180°): Similar to Photoshop's hue shift, but looks different.
